# Personal Portfolio Website – Lab Assignment 2

## Web Development I

**Project:** Personal Portfolio Website (CSS Core)

### About the Project
This project is a personal portfolio website created using HTML and CSS as part of Web Development I Lab Assignment 2.

The website introduces me, displays my technical skills, showcases my projects, and provides a contact form.

### Technologies Used
- HTML5
- CSS3
- Google Fonts

### Website Sections
1. **About Me** – Personal introduction and profile picture.
2. **My Skills** – Table displaying technical skills and levels.
3. **My Projects** – Display of sample projects.
4. **Contact Me** – Contact form with input fields.

### CSS Features Implemented
- External CSS stylesheet
- Element, class, and ID selectors
- Consistent colour theme
- Google Fonts typography
- CSS box model (margin, padding, border)
- Styled navigation bar with hover effects
- Styled skills table
- Customized buttons
- CSS positioning
- Image shadows
- Back-to-top button
- Responsive design
- Smooth scrolling
